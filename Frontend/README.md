# Hardware Store Portal — Frontend

Angular 22 frontend for a hardware store management system, built as a portfolio project.

## Features
- JWT-based authentication with route guards
- Product/inventory management
- Customer management
- Billing and payment tracking

## Tech Stack
Angular 22, TypeScript, RxJS, SCSS

## Setup
1. `npm install`
2. `ng serve`
3. Navigate to `http://localhost:4200`

Requires the [backend API](link-to-your-backend-repo) running locally.
